Niskala Studio - AI Voice Enhancer (Static ZIP - Version B)

This package is a static front-end starter for Niskala Studio.
It includes:
- index.html: main UI
- style.css: amber-white luxury theme
- app.js: client-side logic with placeholders for AI modules

How to deploy:
1. Unzip the folder.
2. Upload the folder to Vercel or any static host (Vercel recommended).
3. After deployment, the site will be live.
